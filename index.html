About / Oscar

I like the part where nobody knows what’s wrong yet.

I’m Oscar, a web designer and developer based in Honduras.

My path into web work wasn’t completely linear. I started in quality analysis, later managed a customer-service team, moved into UX/UI and web design, and eventually spent much more of my time building and supporting production websites.

That background has made me comfortable moving between very different parts of a project — talking with clients, thinking through layout and usability, implementing a design, or digging through an unfamiliar website when something breaks.

WordPress and Shopify are where I’ve spent most of my recent time, but I’m less interested in being tied to a specific platform than I am in understanding how something works and figuring out how to make it better.

And yes, the Mulligan button farther down the page is there for a reason.

    The bug

    Reported

    “Something on the website isn’t working.”

    Reproduction

    Intermittent.

    Symptom

    An important production page works normally for some visitors, but breaks intermittently for others.

    Your move

    Inspect the evidence.

    Browser — clue found

    Console
    No fatal JavaScript errors.
    Network
    One third-party dependency is loading unusually late.
    Cache
    Behavior changes between cached and uncached sessions.

    Application — clue found

    WordPress
    No fatal PHP errors.
    Plugins
    A performance/optimization plugin was recently updated.
    JavaScript
    Some frontend scripts are configured for delayed execution.

    Infrastructure — no obvious issue

    DNS
    Resolving normally.
    SSL
    Valid.
    Server
    Responding normally.
    What’s your hypothesis?
    Root cause

    Delayed JavaScript execution was preventing a required dependency from being available when the page needed it.

    Fix

    Exclude the required scripts from delayed execution and verify the affected workflow under cached and uncached conditions.

    Nice.
