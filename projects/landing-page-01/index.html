Restaurantology Summit 2026

A responsive event experience built in WordPress from a supplied visual direction, combining editorial layouts, a detailed event agenda, speaker content and event information into a single long-form landing page.

Visit live site ↗

Overview

Restaurantology Summit is an annual event for restaurant operators and industry leaders. For the 2026 site, I was responsible for translating the supplied design into a working WordPress experience while preserving its distinctive visual direction across desktop and mobile.

The goal

The build needed to preserve a highly art-directed event identity while organizing a significant amount of practical information — venue details, sessions, speakers, networking information and calls to action — into a page that still felt cohesive and easy to navigate.

Translating the design

The supplied design relied on oversized typography, custom illustration, asymmetric spacing and large shifts in visual rhythm between sections. My role was to recreate that direction within Salient while making sure the layouts remained workable and readable at different viewport sizes.

Building the story

  1. Event introduction
  2. Venue
  3. Agenda
  4. Speakers
  5. Networking
  6. Event information
  7. Archive / Rewind
  8. Partners + call to action

Responsive experience

The desktop design uses a large amount of negative space, oversized artwork and horizontal compositions that could not simply be scaled down. Mobile required re-composing those sections vertically while preserving the typography, artwork and hierarchy of the original direction.

From design to browser

I implemented the page inside an existing Salient WordPress environment, using custom CSS and JavaScript where the builder alone was not enough to reproduce the intended layout and interactions.

Final experience

My role

I was responsible for implementing the supplied web design in WordPress, adapting the layouts for responsive behavior, creating custom frontend styling and functionality, and integrating the event content into the finished page.

Result

The finished page brings the supplied Restaurantology visual direction into a responsive production site while supporting a large event schedule, speaker content and event information without losing the character of the design.
