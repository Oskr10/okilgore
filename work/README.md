1. Project number / category
2. Title
3. Short introduction
4. Metadata — Role, Stack, Project type
5. The problem
6. The investigation / approach
7. The solution
8. Technical details — code, diagrams, screenshots
9. The result
10. What I learned (optional)
11. Next project →

Do not publish client names, private URLs, credentials, customer data or
unredacted payloads. Anonymize where consent is unclear.
